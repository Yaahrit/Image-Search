# Component Documentation

This project uses a modular component architecture. While not using a framework like React, the UI is organized into logical components styled via `css/components.css` and rendered via `js/ui.js`.

### Key Components

1. **Image Card**:
   - Selector: `.image-card`
   - Features: Aspect ratio aware, hover overlay, interactive buttons.

2. **Search Bar**:
   - Selector: `.search-form`
   - Features: Glassmorphism, focus states, voice integration.

3. **Modal**:
   - Selector: `.modal`
   - Features: Fullscreen backdrop blur, sidebar details, image zoom.

4. **Toast**:
   - Selector: `.toast`
   - Variants: Success, Error, Info.
   - Features: Automated entry/exit animations.

5. **Skeleton Loader**:
   - Selector: `.skeleton`
   - Features: CSS shimmer animation matching card layouts.
