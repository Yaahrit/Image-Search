# Asset Icons

All icons in this project are implemented using:
1. **Font Awesome 6 (Web Fonts)**: For standard UI icons (Search, Heart, Trash, etc.)
2. **Inline SVGs**: For custom complex graphics (if any)
3. **Favicon**: Sourced via external CDN for development

To change icons, search for `<i>` tags in `index.html` or JS modules and update the class names.
