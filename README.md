# 📸 Vision — Premium Image Search Engine

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Unsplash API](https://img.shields.io/badge/Powered%20By-Unsplash%20API-black)](https://unsplash.com/developers)
[![Version](https://img.shields.io/badge/Version-1.0.0-blue)](https://github.com/)

**Vision** is a high-performance, modern image search application built with vanilla technologies. It provides a premium, "Awwwards-style" experience with glassmorphism UI, advanced filtering, and professional-grade features.

---

## ✨ Key Features

- 🔍 **Advanced Search**: High-resolution image fetching with Unsplash API integration.
- 🎙️ **Voice Search**: Real-time speech-to-text searching using the Web Speech API.
- ❤️ **Favorites System**: Save and manage your favorite images with persistent `localStorage`.
- 🌙 **Dual Themes**: Seamless dark and light mode toggle with automatic OS preference detection.
- 📜 **Infinite Scroll**: Modern scroll-to-load experience for uninterrupted browsing.
- 🛠️ **Advanced Filters**: Filter results by orientation (Landscape, Portrait, Square) and sort order.
- 🌍 **Multi-Language**: Support for English, Hindi, Spanish, and French.
- ⌨️ **Keyboard Shortcuts**: Power-user shortcuts for search, theme toggling, and navigation.
- 📱 **Fully Responsive**: Optimized for everything from ultra-wide monitors to mobile devices.
- ✨ **Glassmorphism UI**: Beautiful frosted-glass effects, animated background blobs, and smooth transitions.

---

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: CSS3 (Modern Flexbox/Grid, Custom Properties, Keyframe Animations)
- **API**: Unsplash API
- **Icons**: Font Awesome 6
- **Fonts**: Inter & Poppins (Google Fonts)

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Edge, Safari, or Firefox).
- (Optional) A local server for PWA/Module features, though this version is bundled to work via `file://`.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/vision-image-search.git
   ```
2. Navigate to the project folder:
   ```bash
   cd vision-image-search
   ```
3. Open `index.html` in your browser.

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `K` or `/` | Focus Search Bar |
| `T` | Toggle Dark/Light Mode |
| `F` | View Favorites |
| `H` | Open Search History |
| `?` | Show Shortcuts Hint |
| `Esc` | Close Modal/Sidebar |
